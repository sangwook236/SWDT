	- Commands.
		Type # to attach context
			#codebase
			#editor
			#selection
			#terminalSelection
			#terminalLastCommand
			#VSCodeAPI
			#file
			#<filename>
			#sym
			#<symbol>

		Type / to use commands
			/docs
				/docs generate a doxygen comment for foo
			/help
			/clear
			/review
			/refactor

		Type @ to chat with extensions
			@workspace
				/explain
					@workspace /explain how the selected code works
				/tests
					@workspace /tests add unit tests for my code
				/setupTests
				/fix
					@workspace /fix the problems in my code
				/fixTestFailure
				/new
				/newNotebook
			@vscode
				/search
				/startDebugging
				/runCommand
			@terminal
				/explain
			@github
			@remote-ssh
